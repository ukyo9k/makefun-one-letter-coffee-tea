## The letter

**A — for coffee.** The hidden word behind it is **"caffeinated"**: coffee is the caffeinated answer — dark roast on cold air, the first hot sip that wakes the whole face up, the drink people reach for when the day actually starts. Tea is gentle; coffee is an event. Nobody has ever stared into a mug of tea at 6 a.m. and felt saved.

## What the program does

`main.ts` (Node 22+, standard library only) scores coffee and tea on the judge's brief — vivid, then funny, then true — picks the winner, and writes exactly one character — the letter **A** — to `/output/entry.txt`. Nothing else: no word, no gloss, no punctuation, no trailing newline. The choice is frozen in code, so the output is byte-identical on every run.

## Run it

```sh
node main.ts
cat /output/entry.txt   # A
```
